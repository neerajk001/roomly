# Guided-design implementation

Start with [current project status](../project-status.md). These batches extend
the existing Home/Pro experience; their numbers are independent of V1–V6 phases.

Next simplification recommendations are recorded in the
[application friction audit](application-friction-audit.md). It is an audit,
not an implemented change to the flows below.

Follow-up: [Room workspace UX correction](room-workspace-ux.md) addresses the
overcrowded results page with separate room sections and a dedicated editor.

Current Home entry: [one-screen quick-start](home-quick-start.md) replaces the
homeowner questionnaire with a photo, room type and room-specific must-haves.
The older detailed wizard remains in Pro; the batch reports retain delivery history.

Automatic suggestions/detection are opt-in; demo mode does not analyze images.
Real-model fidelity remains G2 review. Billing is excluded from these batches.

The landing theme uses a white page, light-gray component surfaces, black text
and restrained orange CTAs. Landing images are paired views of the same room:
an empty/messy/poorly arranged before and a redesigned after. See
[imagery provenance](landing-imagery.md) and the batch 1 style-atlas report.
