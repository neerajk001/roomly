# Security audit (V6.1 snapshot)

Implementation inventory updated 2026-11-09; this is not a production security
certification. See [current status](project-status.md) for review gates. The
guided-design changes use fake/mocked providers in automated verification.

Every mutation goes through a server action or a route handler. Tenant data is resolved from the
session (`requireWorkspace`/`requireApiWorkspace`) and scoped by `workspaceId`; public pages use
tokens only. Cross-workspace access returns 404.

## Guided-design boundaries

- Clients submit output IDs and validated integer area coordinates, never arbitrary
  image or mask URLs. The server reauthorizes the output and builds the mask.
- The vision adapter receives a server-loaded thumbnail, uses structured output,
  validates object bounds and advice, disables automatic provider retries, and
  does not log image bytes or signed URLs. Demo mode claims no image analysis.
- Targeted output is composited only inside the reviewed rectangle. This protects
  stored outside pixels but does not certify detection accuracy or edit quality.
- Failed/unconfirmed UI submissions are not retried automatically. Status retry
  performs reads only; cleanup aborts old polls and rejects mismatched job IDs.
